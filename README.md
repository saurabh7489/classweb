# 🐍 2D Snake Game (Web)

A simple and interactive **2D Snake Game** built using **HTML, CSS, and JavaScript**.  
This project recreates the classic snake gameplay in a modern browser-based environment with smooth movement, scoring, and game-over detection.

---

## 🎮 Features

- Classic 2D snake movement
- Food generation and score tracking
- Game Over screen with final score
- Keyboard-controlled gameplay
- Simple and clean UI
- Lightweight and fast (no external libraries)

---

## 🛠️ Technologies Used

- **HTML5** – Game structure
- **CSS3** – Styling and layout
- **JavaScript (Vanilla JS)** – Game logic and controls

---

---

## ▶️ How to Play

1. Open `index.html` in your browser  
2. Use keyboard arrow keys to control the snake  
3. Eat the food to increase your score  
4. Avoid colliding with walls or the snake’s own body  
5. Game ends when collision occurs
